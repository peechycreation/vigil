<h1 align="center">Vigil</h1>
<p align="center">Keep your Mac awake. A tiny native menu bar utility.</p>

## Features

- One-click toggle that prevents your Mac from going to sleep
- Timer from 15 minutes to 8 hours, with live countdown, progress bar and end time
- Optional: put the Mac to sleep automatically when the timer ends
- Launch at login
- Native SwiftUI panel, universal binary (Apple Silicon + Intel), zero dependencies

The interface is in French.

## Install

1. Download `Vigil-x.y.zip` from the [latest release](../../releases/latest), unzip it and move `Vigil.app` to `/Applications`.
2. First launch only: the app is not notarized (no paid Apple Developer subscription behind this project), so macOS will warn you. Right-click `Vigil.app` > Open > Open. Alternatively:

```bash
xattr -d com.apple.quarantine /Applications/Vigil.app
```

Requires macOS 13 or later.

## Command line

```bash
open -a Vigil --args --on       # activate (not remembered across launches)
open -a Vigil --args --for 45   # start a 45-minute timer
```

## Build from source

```bash
./build.sh
```

Produces `build/Vigil.app` (ad hoc signed universal binary). Requires Xcode or the Command Line Tools. The app icon and the menu bar glyph are generated by `tools/icongen.swift`.

## How it works

While active, Vigil holds an IOKit power assertion (`PreventUserIdleDisplaySleep`) — the same macOS mechanism `caffeinate` uses. Only the unlimited mode is remembered across launches; timers are not. "Sleep at timer end" triggers `pmset sleepnow` and only fires when the timer expires naturally, never when you stop it yourself.
